---
name: ZERO3 ranking publication
description: Product rules for separating reviewed result edits from the official event ranking.
---

The event leaderboard and public TV must use a versioned official snapshot. A result capture is partial; administrative review makes it eligible, but only an explicit event-level publication makes that revision official. A correction remains pending while the prior published value stays active. Republishing replaces the old contribution instead of counting it twice. RX and SC remain separate, and unresolved ties or unconfigured scoring rules must not be broken arbitrarily.

**Why:** The user requires review and explicit publication as separate stages, with stable public results until an administrator confirms a new ranking revision.

**How to apply:** Keep result editing, battery publication, and event-wide ranking publication as distinct operations. Preserve the previous published snapshot on edits, require an authorized administrator for publication, and make the ranking/TV consume only published values.
